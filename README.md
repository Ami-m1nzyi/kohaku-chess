# Kohaku — шахматы в своём ритме

Браузерные шахматы с игрой против бота, приглашениями для друга, дневником настроения и магазином оформления. Интерфейс доступен на русском и английском языках.

[Сайт проекта](https://kohaku-chess.vercel.app/) · [Видео для сдачи — 1:31](https://kohaku-chess.vercel.app/demo.html) · [Репозиторий GitHub](https://github.com/Ami-m1nzyi/kohaku-chess)

Проект состоит из HTML, CSS и JavaScript в `dist/`, локального Node.js-сервера и API для заявок на покупку. Правила шахмат проверяет chess.js, бот работает в Web Worker, онлайн-партии используют PeerJS/WebRTC. Для хранения заявок используется PostgreSQL; проект подготовлен для размещения на Vercel с базой Neon.

## Запуск на компьютере

Нужен Node.js 20 или новее. Из папки проекта выполните:

```sh
npm ci
npm run build
npm start
```

Откройте [http://127.0.0.1:4173/](http://127.0.0.1:4173/). В Windows при ограничении запуска PowerShell-скриптов используйте `npm.cmd` вместо `npm`.

`npm start` запускает сайт и обработчики `/api/orders` и `/api/admin`. Без переменных базы данных можно играть и пользоваться дневником, но покупать предметы и проверять платежи нельзя. Настройка описана в [PAYMENTS_SETUP.md](PAYMENTS_SETUP.md). Открывать `index.html` двойным щелчком не следует: модули и Web Worker требуют HTTP.

## Возможности

- Партия с другом на одном устройстве; этот режим выбран при первом входе.
- Партия онлайн по ссылке или коду приглашения.
- Бот с тремя уровнями сложности; подсказка и отмена хода в доступных режимах.
- Шах, мат, пат, рокировка, взятие на проходе и выбор фигуры при превращении. Ничьи по повторению позиции, правилу 50 ходов и недостатку материала.
- История ходов и экспорт PGN; партии без ограничения времени или по 5, 10, 15 минут.
- Настроение до и после игры, заметка о партии и дневник последних записей.
- Профиль с именем и аватаром; магазин дизайнов фигур, цветов фигур, досок и аватаров, включая «Кохаку · Волна».
- Ручная проверка перевода владельцем: покупка открывается после одобрения заявки в закрытой панели.
- Поворот и увеличение доски, полноэкранный режим и режим концентрации.
- Шрифт Jura, отдельные темы для друга и бота, статичный фон без звуков и скрывающего фигуры тумана.

Бот использует minimax с alpha-beta и ограничением времени; это учебный соперник без присвоенного рейтинга.

## Хранение данных и ограничения

Профиль идентифицируется случайным секретным ключом, сохранённым в браузере. Подтверждённые покупки хранятся на сервере и привязаны к этому ключу. Это ещё не аккаунт с email и паролем: автоматической синхронизации между устройствами и восстановления после удаления данных браузера нет. Дневник, текущая локальная партия и настройки также сохраняются в этом браузере.

Онлайн-партии требуют интернета и подключения обоих игроков. Связь зависит от PeerJS/WebRTC и сетевых ограничений; это не рейтинговый сервер с защитой от вмешательства клиента.

Сайт не принимает данные банковской карты и не получает уведомления от Kaspi или Halyk. Владелец самостоятельно сверяет поступление денег в банковском приложении. Нажатие «Я перевёл(а)» только передаёт заявку на проверку.

## Проверка проекта

```sh
npm test
npm run build
node --check dist/app.js
node --check api/orders.js
node --check api/admin.js
```

Дополнительно перед публикацией проверьте в браузере партию до мата, ответ бота, сохранение дневника, два клиента онлайн и обе ветки проверки заказа: одобрение и отказ. Для неоплаченного предмета должна отображаться покупка; примерка доступна после добавления предмета в коллекцию.

## Публикация

Vercel использует `npm run build`, публикует папку `dist/` и запускает обработчики из `api/`. На обычном статическом хостинге будет доступна игра, но для магазина понадобится отдельный сервер API. Переменные окружения задаются в настройках хостинга; секреты и платёжные реквизиты не добавляются в репозиторий.

Готовое видео длится 91 секунду; ссылка и сценарий находятся в [DEMO.md](DEMO.md).

## Структура

| Путь | Назначение |
| --- | --- |
| `dist/index.html`, `dist/style.css` | Интерфейс и оформление |
| `dist/app.js`, `dist/i18n.js` | Партия, профиль, магазин, дневник и перевод |
| `dist/engine.js`, `dist/bot-worker.js` | Бот |
| `dist/pieces.js`, `dist/assets/` | Фигуры и графика |
| `dist/admin.html` | Вход и панель владельца |
| `api/` | Заявки, проверка покупок, сессия владельца и база данных |
| `server.mjs` | Локальный HTTP-сервер |
| `tests/` | Автоматические проверки |
| `scripts/build.mjs`, `vercel.json` | Подготовка зависимостей и настройка размещения |

Лицензии сторонних библиотек нужно сохранять вместе с их файлами. Изображения в проекте не следует считать автоматически доступными для свободного коммерческого использования: права на них принадлежат соответствующим авторам.
