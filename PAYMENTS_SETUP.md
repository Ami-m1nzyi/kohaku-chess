# Заявки на покупку и панель владельца

Покупатель переводит деньги самостоятельно через Kaspi или Halyk. Сайт хранит заказ и его статус, а владелец проверяет поступление в банковском приложении и одобряет либо отклоняет заявку. Автоматического подтверждения из банка нет.

## Настройка окружения

Подключите PostgreSQL, например Neon через интеграцию Vercel, и задайте переменные окружения сервера:

| Переменная | Назначение |
| --- | --- |
| `DATABASE_URL` | Строка подключения PostgreSQL. Также поддерживаются `POSTGRES_URL` и `POSTGRES_PRISMA_URL`; достаточно одной строки подключения. |
| `ADMIN_PASSWORD` | Отдельный длинный пароль для входа владельца. |
| `ADMIN_SESSION_SECRET` | Случайная секретная строка не короче 32 символов для подписи сессии. |
| `TRANSFER_PHONE` | Номер для банковского перевода, показываемый покупателю после создания заказа. |
| `TRANSFER_RECIPIENT` | Имя получателя, с которым покупатель сверяет перевод в приложении банка. |

Значения задаются в Vercel → проект → **Settings → Environment Variables**. Не добавляйте настоящие значения в GitHub, снимки экрана или записи демонстрации. После изменения переменных создайте новое развёртывание. Выберите план базы данных и регион с учётом своих условий; принятие условий сервиса выполняет владелец аккаунта.

Для локальной проверки серверу нужны эти же переменные. `npm start` читает переменные процесса, но не загружает `.env` автоматически. С Node.js 20.6 или новее можно создать исключённый из Git файл `.env.local` и запустить:

```sh
node --env-file=.env.local server.mjs
```

Для локальной проверки используйте отдельную тестовую базу. Продажи проверяйте на HTTPS-развёртывании: сессия владельца использует защищённую HttpOnly-cookie.

## Путь покупателя

1. Покупатель создаёт профиль в браузере и выбирает предмет в магазине.
2. Сайт проверяет товар и цену на сервере, затем создаёт заказ. До успешного создания заказа реквизиты не показываются.
3. Покупатель переводит точную сумму и, если банковское приложение позволяет, указывает номер заказа в комментарии.
4. Кнопка «Я перевёл(а), отправить на проверку» меняет статус на «На проверке». Предмет пока не открывается.
5. После одобрения владельцем предмет попадает в коллекцию. Его можно применить и примерить. При отказе покупатель видит статус и указанную причину.

Если база или API недоступны, сайт сообщает об ошибке и просит не отправлять перевод. Повторная загрузка страницы сама по себе не подтверждает оплату.

## Доступ владельца

Откройте `/admin.html` на том же домене, что и игра, и введите `ADMIN_PASSWORD`. Эта страница предназначена для владельца: сервер проверяет сессию при чтении заявок и принятии решения. Знания адреса страницы недостаточно для доступа.

Для каждой заявки сравните товар, сумму, время и номер заказа с фактическим поступлением в приложении банка. Нажмите «Одобрить» только после сверки. Если перевод не найден или данные не совпадают, отклоните заявку и укажите понятную причину. Решение хранится в базе. Отклонение заявки не выполняет возврат денег: при необходимости возврат делает владелец через банк.

Пароль панели и секрет сессии хранятся отдельно от репозитория. Покупателям нельзя передавать их или ссылку на настройки проекта Vercel.

## Проверка перед приёмом покупок

- Неавторизованный запрос не должен получать список заявок или менять статус заказа.
- Заказ создаётся с серверной ценой; клиент не может назначить свою сумму.
- Неоплаченный предмет показывает «Купить»; кнопки примерки и применения доступны у предметов коллекции.
- Сообщение покупателя о переводе отправляет заказ на проверку, но не выдаёт предмет.
- Одобрение владельца открывает предмет у соответствующего покупателя; отказ его не открывает.
- Покупатель видит изменение статуса после обновления данных; повторная проверка не дублирует покупку.
- При отключённой базе, пустом ответе или сетевой ошибке отображается понятное сообщение.

Покупки привязаны к случайному секретному ключу профиля в браузере, а подтверждённые права на предметы хранятся в базе. Полноценного входа и восстановления профиля на другом устройстве пока нет. Не очищайте данные браузера, если хотите сохранить доступ к текущему профилю.
